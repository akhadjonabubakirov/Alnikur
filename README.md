# Alnikor · Склад — Учёт движения товаров

Веб-приложение складского учёта Alnikor (приход/расход), построенное на шаблоне Excel **Alnikor_Sklad_Kirim_Chiqim_Rus_oylik**.

## Возможности
- **Аналитика** — периоды: день / неделя / месяц / квартал / год / всё время; фильтр по товару; KPI (приход, расход, остаток, оборот); графики по товарам (кг и сум), динамика по времени; ежемесячный пивот-отчёт по каждому товару.
- **Склад (остатки)** — по каждому товару: приход/расход в кг и шт, остаток, средняя цена, стоимость остатка.
- **Операции** — журнал с колонками из Excel-шаблона (дата, вид операции, товар, упаковка, кг, шт, цена за 1 кг, сумма, состояние, кто принял, передача...).
- **Админ** (кнопка 🔒 сверху, пароль `12345678`) — форма ввода операций; для остальных — только просмотр аналитики.
- **Скачать Excel (CSV)** — экспорт всех операций (открывается в Excel).
- Языки: **Русский / Беларуская** (кнопка BE).

## Как открыть
Один файл `index.html` — без сборки и без интернета (все графики встроены). Откройте в браузере или включите GitHub Pages: Settings → Pages → ветка `main` → `https://akhadjonabubakirov.github.io/Alnikur/`.

## Данные
Исходные данные из Excel-файла (лист «Октябрь» 2026): Лезунец для КРС, Концентрат для КРС, Добавка кормовая ПРОАМИД, Алнисон. Новые операции сохраняются в браузере (localStorage).
